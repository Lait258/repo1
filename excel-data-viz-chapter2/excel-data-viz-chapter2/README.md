# 简介
复现《Excel数据可视化——从图表到数据大屏》第二章全部 30 个图表。
数据源见data文件夹，全部使用 Matplotlib / Pandas 实现。

# 目录结构

```
excel-data-viz-chapter2/
├── data/                         
│   ├── 第二章 图表(前15).xlsx
│   └── 第二章 图表(后15).xlsx
├── scripts/
│   ├── part1_charts_01_15.py      # 图 01–15
│   └── part2_charts_16_30.py      # 图 16–30
├── figures/                       # 全部输出 PNG（29 张）
├── requirements.txt
└── README.md
```

> 注：原工作簿中「20 南丁格尔（PPT）」与「20 南丁格尔圆环图」数据重复，
> 30 图中保留圆环图一份，PPT 版仅作配色参考。

# 运行

```bash
pip install -r requirements.txt
python scripts/part1_charts_01_15.py
python scripts/part2_charts_16_30.py
```

脚本内数据/输出路径基于仓库绝对路径，在仓库根目录（或任意目录）执行均可。
